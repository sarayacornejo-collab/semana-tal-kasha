# Semana en Tal Kasha

Rutina semanal de Dofus de Sebastián, publicada con GitHub Pages desde `main`. Todo vive en `index.html`.

- Es una base, no una regla. Usa los nombres de Dofus en español.
- Para ajustar una semana puntual edita `WEEKS`. Para la rutina fija edita `BASE`.
- Para un mes nuevo de Almanax agrega filas a `ALM` y semanas a `WEEKLIST`, con datos de api.dofusdu.de.
- No cambies las claves `tk-*` de localStorage: ahí está el avance guardado.
- El sitio es público: no pongas datos personales.
